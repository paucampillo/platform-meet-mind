## 🎨 Prompt para Figma AI

> Diseña una interfaz moderna y profesional para la funcionalidad **“Sistema Inteligente de Notificaciones”** dentro de la aplicación MeetMind AI.
>
> La interfaz debe verse como parte de una plataforma SaaS de productividad y colaboración basada en inteligencia artificial. El diseño debe ser **limpio, avanzado, intuitivo y user-friendly**.
>
> ### Estructura de la pantalla
>
> Crear una **pantalla de dashboard de notificaciones** con los siguientes elementos:
>
> **1. Barra superior**
>
> * Título: **Notificaciones Inteligentes**
> * Icono de campana con indicador de notificaciones nuevas
> * Filtros:
>
>   * Todas
>   * Reuniones
>   * Tareas
>   * Proyectos
>
> **2. Panel principal de notificaciones**
> Mostrar tarjetas organizadas con diferentes tipos de alertas:
>
> * 📅 **Reunión próxima**
>   “Reunión Sprint Marketing comienza en 30 min”
>
> * ✅ **Tarea próxima a vencer**
>   “Diseñar landing page – vence mañana”
>
> * ⚠️ **Tarea retrasada**
>   “Informe mensual – retrasado 2 días”
>
> * 📊 **Actualización de proyecto**
>   “Proyecto App Mobile actualizado”
>
> Cada tarjeta debe incluir:
>
> * icono visual
> * responsable
> * fecha límite
> * botón rápido: *Ver / Marcar como hecho / Posponer*
>
> **3. Panel lateral de IA (Smart Suggestions)**
> Una columna lateral donde la IA muestra sugerencias como:
>
> * “3 tareas prioritarias hoy”
> * “Reunión en 1h – revisa tareas pendientes”
> * “2 tareas podrían retrasarse”
>
> **4. Indicadores visuales**
> Usar colores para prioridad:
>
> * Verde → completado
> * Amarillo → próximo
> * Rojo → retrasado
>
> ### Diseño visual
>
> * Estilo **SaaS moderno tipo Notion / Linear / Slack**
> * Interfaz minimalista y profesional
> * Uso de iconos claros para notificaciones
> * Tarjetas con sombra suave
> * Bordes redondeados
> * Espaciado amplio para buena legibilidad
>
> ### Paleta sugerida
>
> * Azul tecnológico
> * Morado IA
> * Fondo claro o gris muy suave
>
> ### Experiencia de usuario
>
> * Información clara en pocos segundos
> * Interacciones simples
> * Diseño centrado en productividad
> * Fácil de escanear visualmente
>
> La pantalla debe transmitir **control, organización y asistencia inteligente del sistema**.
